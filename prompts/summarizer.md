# 任务目标

请根据提供的历史会话，生成一段简洁且信息完整的摘要。这段摘要将用于替换原有的历史记录，作为后续对话的上下文（Context）。

# 执行指令
1. 提取核心信息：识别并保留对话中的关键要素，包括：用户的核心意图、已完成的操作、重要的数据结果、待解决的问题、以及未完成的任务。
2. 保持客观准确：仅总结已发生的事实，不要添加推测或无关信息。如果涉及代码或命令，请确保准确无误地引用。
3. 逻辑连贯：生成的摘要应是一段通顺的自然语言，或清晰的要点列表，确保智能体阅读后能无缝衔接当前的对话状态。
4. 忽略冗余：过滤掉寒暄、重复确认、无意义的闲聊以及失败的尝试（除非失败原因对后续很重要）。
5. 适当保留核心数据：对于任务直接相关的核心数据，应当直接保留。

# 输出格式

参考以下 Markdown 格式输出总结内容：

```markdown
# 核心进展
- 关键步骤1：用户做了什么，得到了什么结果
- 关键步骤2：执行了什么命令，输出了什么
- 关键步骤3：...

# 核心数据
- 核心数据1
- 核心数据2

# 当前待办/阻塞
- 用户当前正在等待的结果或下一步计划
- 存在的问题或报错

# 关键上下文
- 需要特别注意的配置、变量值或背景信息
```
